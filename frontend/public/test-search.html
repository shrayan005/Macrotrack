Open DevTools (F12) and:

  1. Go to Console tab - Look for errors
  2. Go to Network tab - Filter by "XHR"
  3. Click "Test API" button above and watch Network tab
  4. Look for request to: /api/foods/search/
  5. Check Status: Should be 200, not 401 or 500
